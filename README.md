## Strata — AI IDE for Claude Code (Windows)

The [`strata/`](strata/) folder contains **Strata**, a Windows desktop app (Electron + React + TypeScript).
It wraps the installed Claude Code CLI in a modern IDE-style interface: open any folder, and Claude Code works
inside it. Strata also includes a chat, a Monaco editor with diff review, a PowerShell terminal, Git, and
Blender / Roblox Studio integration. See [strata/README.md](strata/README.md).
